# Aircraft Landing Problem

This example models aircraft landing order and timing with an OptAgent list permutation and a
recursive array.

## Setup

From the main OptAgent repository, install the development dependencies:

```bash
./.venv/bin/python -m pip install -r requirements-dev.txt
```

## Run

Start Jupyter from this directory and open `aircraft_landing_problem.ipynb`:

```bash
cd examples/examples/hexaly/aircraft_landing_problem
jupyter notebook aircraft_landing_problem.ipynb
```

Run the notebook cells in order. The bundled `instances/` directory contains the reproducible
OR-Library inputs used by the example.
