# Quickstart Examples

The public documentation uses three short examples:

- `unified_solve.py`: `ModelBuilder` plus the general `solve(...)` route.
- `../linear/quickstart_linear_routes.py`: the same linear model through
  `solve(...)` and the exact `solve_optx(...)` route.
- `../scheduling/job_shop_small.py`: a structured scheduling model through the
  third-party `solve_cpsat(...)` route.
